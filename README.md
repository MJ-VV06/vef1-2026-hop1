### Upplýsingar til að keyra verkefni
Notaðu _npm run dev_ til að keyra verkefnið.
Notaðu _npm run lint_ til að stylelinta það.
### Uppsetning
Verkefnið er byggt úr html og css síðum. Allar html síður fyrir utan _index.html_ eru í _sidur_ möppunni og allar css síður fyrir utan _styles.css_ eru í _styles_ möppunni. Þetta verkefni er með _stylelint_, _parcel_ og _prettier_.
